# 文档中心

> 全部文档按 **从零到部署** 的顺序编号。新用户请从 `01` 开始按序阅读，
> 每篇结尾都有「下一步」指向下一篇，不需要自己找路。

---

## 一、新手主线（按顺序读完即可上线）

**这 6 篇是主线，按编号顺序读，读完就能把服务部署上线。**

| # | 文档 | 读完你会 | 预计耗时 |
|---|---|---|---|
| 01 | [项目概述](./01-overview.md) | 明白这项目是什么、能干什么、三种部署形态怎么选 | 5 分钟 |
| 02 | [环境准备](./02-prerequisites.md) | 装好 Node / 依赖，克隆仓库，确认环境可用 | 10 分钟 |
| 03 | [本地开发与验证](./03-local-development.md) | 在本机跑起来、进管理面、验证回源全链路 | 20 分钟 |
| 04 | [配置详解](./04-configuration.md) | 看懂每个配置字段的含义与填法 | 按需查阅 |
| 05 | [命令行部署](./05-deploy-cli.md) | 用 `wrangler` 命令把服务部署到线上 | 20 分钟 |
| 06 | [可视化部署](./06-deploy-dashboard.md) | 完全不碰命令行，在控制台点完整个部署 | 25 分钟 |

> **05 和 06 是两条并列的路，任选其一即可，不要同时做。**
> - 习惯命令行、想要可复现的部署 → 走 **05**
> - 不想装任何工具、只想点鼠标 → 走 **06**
