# 状态码说明

> [!NOTE]
> **本文面向**：所有人（排障时查表用）。
> 这里的「源站」指你接入网关背后的真实服务器；「节点」指 cdn-edge-gateway 跑的边缘节点。

访问经过网关的资源时，可能遇到下面这些状态码。绝大多数由**源站**或**边缘节点**返回，
网关本身只会返回少量自有状态码（见文末「网关自有状态码」）。

---

## 4xx —— 客户端 / 请求侧问题

| 码 | 含义 | 常见原因与解决 |
|---|---|---|
| 400 | Bad Request 错误请求 | 请求参数本身有问题。检查入参合法性后重试。 |
| 401 | Unauthorized 未授权 | 缺身份凭据。带上正确凭据或先在源站授权。 |
| 403 | Forbidden 禁止 | 源站理解请求但权限不足。给请求开对应权限。 |
| 404 | Not Found 未找到 | 源站找不到资源。检查 URL 路径是否对外暴露。 |
| 405 | Method Not Allowed 方法不允许 | 用了源站不支持的 HTTP 方法（GET/POST/PUT…）。改方法。 |
| 406 | Not Acceptable 不可接受 | Accept 协商头源站不支持。改 Accept 头。 |
| 407 | Authentication Required 需代理验证 | 经过代理源站但缺代理凭据。带正确代理凭据。 |
| 408 | Request Timeout 请求超时 | 源站没在合理时间收全请求。减小包体或延长源站处理时长。 |
| 409 | Conflict 冲突 | 与资源当前状态冲突（如并发编辑）。刷新重提或加冲突处理。 |
| 410 | Gone 已消失 | 资源被永久删除。移除引用。 |
| 411 | Length Required 需长度 | 缺 Content-Length。带上或改用 `Transfer-Encoding: chunked`。 |
| 412 | Precondition Failed 先决条件不满足 | 源站要求的预置条件未满足。带正确条件。 |
| 413 | Payload Too Large 包体过大 | 超过源站上限。减文件体积。 |
| 414 | URI Too Long URI 过长 | URI 太长。缩短或拆多次。 |
| 415 | Unsupported Media Type 媒体类型不支持 | Content-Type 源站不支持。改类型。 |
| 416 | Range Not Satisfiable 范围不满足 | Range 头范围非法。改 Range。 |
| 417 | Expectation Failed 期望失败 | Expect 头源站不满足。禁用 Expect 头。 |
| 418 | 非标准码 | ESA/源站不会主动返回；多由源站反爬/限流或下载工具断点续传产生。排查源站策略。 |
| 429 | Too Many Requests 请求过多 | 触发源站限流。稍后重试。 |
| 498 | Blocked for Security Throttling（ESA 扩展） | ESA 边缘 WAF 强安全模式下过载拦截。检查流量洪峰；必要时切回 Bypass 模式。 |
| 499 | Client Close Request 客户端关闭 | 客户端主动断开，前端无感知，无需处理。 |

## 5xx —— 服务端 / 源站侧问题

> [!WARNING]
> 520~599 多为 ESA 对错误场景的细化扩展，标准 HTTP 不存在。业务上建议避免使用此范围自定义码以免混淆。

| 码 | 含义 | 常见原因与解决 |
|---|---|---|
| 500 | Internal Server Error 内部错误 | 源站自身出错。查源站日志，或回退上一个正常版本。 |
| 502 | Bad Gateway 网关错误 | **节点连不上源站**（最常见）。确认源站可用 + 防火墙放行节点 IP。详见 [502 错误说明](502.md)。 |
| 503 | Service Unavailable 服务暂不可用 | 源站过载。查源站负载。 |
| 504 | Gateway Timeout 网关超时 | 节点连不上源站（超时型）。检查源站状态或加大超时。 |
| 508 | Loop Detected 检测到循环 | 请求在 ESA 网络循环超限。检查源站循环终止条件。 |
| 520 | 源站返回未知错误 | 源站返回空/未知/意外响应。查源站崩溃或 DB 错误。 |
| 521 | 源站已关闭 | 源站拒绝连接。确认源站可用 + 节点在白名单。 |
| 522 | 连接超时 | 节点与源站连接超时。确认源站放行节点 IP。 |
| 523 | 无法访问源站 | 节点连不上源站。确认 DNS 已加源站 IP、排查路由。 |
| 524 | 出现超时 | 连上源站但 30s 内未返回。优化源站性能或加大回源超时（1~300s）。 |
| 525 | SSL 握手失败 | 节点与源站 SSL 握手失败。配正确证书与加密套件。 |
| 526 | SSL 证书无效 | 节点无法验证源站证书。更新证书。 |
| 530 | 无法解析源站主机名 | 节点解析不了源站域名。确认源站主机名可解析。 |
| 581 | 超过最大执行跳数 | 边缘函数循环调用超限。改代码避免循环。 |
| 582 | 获取版本失败 | 拉边缘函数版本失败。重新发布脚本。 |
| 583 | 触发限流（边缘函数） | 超边缘函数处理上限。联系平台。 |
| 584 | 计算资源不足 | 节点算力不足。联系平台。 |
| 594 | 未捕获异常 | 边缘函数未捕获异常卡住。处理异常后重试。 |
| 595 | 执行时间超限 | 边缘函数超 120s 上限（EdgeOne 单次请求执行上限）。优化脚本 CPU 耗时。**回源总时间预算**据此推导：硬顶 = `maxExecutionMs − safetyReserve`（esa=2000 / cf、eo=5000），详见 [请求流程 · 状态语义边界](/dev/12-request-flow.md)。 |
| 596 | 配置拉取失败 | 边缘函数配置拉取失败。控制台重下发配置。 |

> [!NOTE]
> **各平台单次请求执行上限（用于推导回源总时间预算硬顶）**
> | 平台 | 总执行上限（墙钟） | 网关首字节约束 | 说明 |
> |---|---|---|---|
> | EdgeOne | 120s（595 码） | 无 | 见上 |
> | Cloudflare Workers | 30s（默认挂钟） | 无 | Worker 默认 30s CPU 墙钟；回源不受 CPU 限制 |
> | ESA | 120s | **10s**（超时网关主动断连返回 504） | 阿里云《什么是函数和Pages》：函数单次执行响应时间不超过 120 秒（等待 I/O 也算 RT）；网关等待函数返回首个数据超 10s 断连 |
>
> 三者均支持环境变量 `EXECUTION_LIMIT_MS` / `FIRST_BYTE_LIMIT_MS` 覆盖（测试 / 特殊部署）。
| 598 | 调试器异常 | 边缘函数调试器异常。检查代码/debugger session。 |
| 599 | 脚本执行异常 | 边缘函数语法错误或资源超限。查脚本。 |

## 网关自有状态码（cdn-edge-gateway 直接返回）

| 码 | 含义 | 说明 |
|---|---|---|
| 502 | 回源失败（全源站链回退后仍失败） | 数据面所有源站都连不上/超时，网关返回 502 兜底页。见 [502 说明](502.md)。 |
| 403 | 安全拦截 | 防盗链 / IP 黑名单 / UA 过滤命中，网关直接拒绝。 |
| 401 | 管理面未登录 | 访问 `/__panel/api/*` 写操作未带登录态。 |
| 429 | 网关限流 | `security.rateLimit` 触发（按客户端 IP/路径计数）。 |

> [!TIP]
> 想知道某个 5xx 到底是「源站挂了」还是「网关没连上」，优先看 [502 错误说明](502.md) 的排查清单。
